# Ресурсы

Фотографии пользователя находятся в `../images/`, оригиналы 640×640 и AI-улучшенные версии 1254×1254 WebP. Шрифты Manrope и Cormorant Garamond поставляются через Fontsource и обслуживаются локально через next/font/local. Здесь находятся копии лицензий OFL. Для замены фотографий сохраняйте имена файлов или обновите `app/page.jsx`, Open Graph и JSON-LD.
